# Dermatology, Taihe Hospital, Shiyan City — Research Repository

Reproducible code, aggregate data and outputs for research from the Department of
Dermatology, Taihe Hospital, the Affiliated Hospital of Hubei University of Medicine,
Shiyan 442000, Hubei, China.

Correspondence: Zhen Wang (sywz1998@163.com).

## Contents

| Directory | Project |
|---|---|
| `dfsp-transcriptome/` | Multi-cohort transcriptomic integration of dermatofibrosarcoma protuberans (DFSP) — diagnostic signature, immune-cold microenvironment and drug vulnerabilities. See its own `README.md`. |
| `nndrs-syphilis-validation/` | Parallel-series triangulation of the GBD 2023 modelled syphilis burden against three official Chinese notification series — fifteen released datasets, analysis code, tables 1–7 and figures 1–5. See its own `README.md`. |

All input data used in this repository are publicly available aggregate or
publicly archived datasets; no individual-level or identifiable patient data are
included.
